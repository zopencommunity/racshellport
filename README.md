## racshell

racshell is an open source RACF shell interface for z/OS Unix SSH sessions. It provides a set of command-line tools for managing RACF users, groups, datasets, resources, and keyrings via the z/OS Security Administrator interface (SEAR).

racshell is built on top of [sear](https://github.com/Mainframe-Renewal-Project/sear), a C++ library for RACF administration.

For more info please visit: [https://github.com/Mainframe-Renewal-Project/racshell](https://github.com/Mainframe-Renewal-Project/racshell)
